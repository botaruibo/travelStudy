# 文档总览

本目录是 `travel-study-electron` 的产品、技术和 UX 设计资料归档。文档以当前 MVP 为基线，后续需求和架构变更应在对应目录中新增版本或变更记录。

## 文档分类

| 分类 | 入口 | 内容 |
| --- | --- | --- |
| 产品 | [product/README.md](product/README.md) | 用户旅程、MVP 范围、验收标准、用户手册 |
| 技术 | [technical/README.md](technical/README.md) | Electron、React、视频处理、AI 分析、PDF 生成等技术架构 |
| 设计 | [design/README.md](design/README.md) | UX 设计规格、配色、交互状态和 Demo 说明 |
| 参考 | [reference/README.md](reference/README.md) | 外部参考、研究记录和素材来源 |

## 文档维护约定

- 产品需求、技术架构和视觉规范分开维护，避免把实现细节混入需求文档。
- 版本号写入文件名或文档标题；重大变更补充变更记录。
- Demo 以 `renderer/` 的 React 代码为准，旧版演示文件仅作为历史参考，不作为实现源文件。

## 设计基线

- 面向中国大城市中小学家长，重点建立专业可信赖感，同时保留成长探索感。
- 主色使用深青蓝，教育/探索状态使用森林绿，行动按钮使用琥珀橙。
- 主工作台遵循“左侧场景列表—中间关键帧工作区—右侧检查器”的视频生产结构。
- H5 模板使用照片主导、纸张留白和知识卡片层次，避免复制任何外部平台的具体作品。

# 游学纪 Web UX 设计规格

## 视觉方向

- 主题：专业桌面工作台 × 植物观察手账。
- 模板参考提炼：基于用户提供的“小红书研学手册”方向，保留照片主导、胶带/标本签层次、少量手写批注和充分留白；更重要的是把“学习目标—观察证据—知识卡—反思问题—结论”作为页面骨架，不复制任何具体作品或平台品牌。
- 视频工作台参考提炼：借鉴 Storyboard 的视频元信息、镜头编号与时码、网格/列表/时间轴多视图、批量选择和任务进度反馈，但改写为中小学研学内容生产语言。
- 背景锁定：应用画布使用暖米白 `#F5F5F0`；预览舞台使用浅灰 `#ECECEA`；H5 模板纸张延续米白并保留纸张纹理。
- 家长决策配色：深青蓝 `#1E3A5F` 作为导航与结构主色，森林绿 `#2D5A4A` 表达教育与探索，琥珀橙 `#E8913A` 作为主要行动色，自然青 `#5B9A8B` 与砖红 `#B85450` 仅用于状态/维度点缀，正文使用深灰 `#1F2937`，避免纯黑和高饱和色。
- 配色比例：主色约 60%，行动/强调约 30%，中性色约 10%；列表和内容区保持中性色主导，关键 CTA 使用琥珀橙形成清晰决策路径。
- 字体：应用 UI 使用系统中文无衬线；模板标题和单条批注可使用楷体回退。

## 容器与组件

- 应用壳：左侧导航、顶部项目栏、主工作区、底部阶段操作条。
- 内容模型：列表、轨道、开放式画布和检查器；避免默认卡片墙。
- 圆角：控件 8px、主面板 12px；阴影仅用于模板纸张和模态框。
- 图标：Lucide 线性图标，统一 1.8px 线宽。
- 状态：未选、部分选、全选必须同时用形状和颜色表达。

## 可见文案锁定

- 品牌：游学纪。
- 导航：工作台、视频加工、游学片段、游学笔记、模板中心。
- 流程：选择素材、校订文字、选择模板、生成。
- 核心标题：挑选要进入游学片段的内容、校订场景文字、选择游学片段模板。
- 默认模板：自然观察手账（默认）。
- H5 页面标题：植物 A：叶片的秘密。
- 主要操作：下一步：生成文字、下一步：选择模板、生成游学片段 PDF。

## 响应式规则

- ≥ 1180px：三栏桌面工作区。
- 760–1179px：隐藏检查器，保留导航与主编辑区。
- < 760px：隐藏桌面侧栏，模板预览改为单列，底部提供大触控按钮；禁止横向溢出。

## 核心交互

- 点击场景：全选或全不选其关键帧。
- 点击关键帧：场景自动更新为未选/部分/全选。
- 转写文本可编辑，并保留低置信度提示。
- 模板设置实时改变 H5/CSS 预览。
- 生成、合并均提供处理态与成功态。
- 网格/列表/时间轴视图共享同一份选择状态，切换视图不丢失选择结果。
